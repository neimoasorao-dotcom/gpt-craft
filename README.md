# WILDBOUND

**野生の、その先へ。** シードで生まれる世界を旅し、資源を集め、道具を作り、自分の居場所を育てる、一人称3Dボクセルサバイバルです。コード、ピクセルテクスチャ、生物モデル、UI、音楽と効果音は本作のために制作しています。

## 起動

Node.js 22.12 以上を使用してください（この環境では Node.js 24 で検証）。

```sh
npm ci
npm run dev
```

ブラウザで開き、「新しい冒険へ」から世界の名前・シード・モードを選びます。画面をクリックするとマウスで視点を操作できます。WebGL 2 と、マウス・キーボードに対応したブラウザが必要です。

```sh
npm run build       # dist/ に本番用ファイルを生成
npm run preview     # 本番ビルドを確認
npm test            # 地形・メッシュ・物理・クラフト・保存・AI のテスト
npm run test:e2e    # 起動中のサーバーで移動・採掘・クラフト・保存など17項目を確認
npm run test:features    # 箱・農業・ベッド・星の標・バックアップなど8項目を確認
npm run test:performance # 品質と自動調整の設定ごとに実際のフレーム時間を記録
npm run format:check     # ソースの書式を確認
```

E2E は既定で `http://127.0.0.1:5173` と `/usr/bin/chromium` を使用します。`GAME_URL` と `CHROMIUM_PATH` で変更できます。検証結果とスクリーンショットは `artifacts/` に生成されます。

## 操作

| キー | 操作 |
| --- | --- |
| WASD / マウス | 移動 / 視点 |
| Space | ジャンプ、泳ぐ、翼衣装備中は空中で滑空 |
| Shift / Ctrl | ダッシュ / しゃがむ |
| 左ボタン長押し | 採掘、敵に照準を合わせて攻撃 |
| 右ボタン | ブロック設置、設備を使う、食べる |
| 1–9 / ホイール | ホットバー切り替え |
| E | 持ちもの・クラフト |
| F | 工作台・炉・箱・ベッドを使う |
| R / Q | 食べる / 1個落とす（Shift+Q でスタック） |

持ちものはクリック2回またはドラッグで移動、右クリックで半分、Shift+クリックでホットバーとバックパック間を移します。防具を選んで「装備する」を押すと着用します。箱では Shift+クリックで預け、箱の中身をクリックして取り出せます。

## 旅のはじめ方

木の幹を採掘し、E で板と枝、木の道具を作りましょう。板6個の工作台を設置すると、近くで石の道具や炉を作れます。炉のそばでは鉱石と石炭を使って製錬できます。土・草はシャベル、木は斧、鉱石はつるはしで効率よく採れます。鉱石には回収に必要な道具の Tier があり、適切な道具がなければ壊せても回収できません。

夜と地下には危険な生物が現れます。食料、灯り、防具を用意して探索してください。松明やランタンは、見通しのある周囲で敵の出現を抑えます。設置したベッドは復帰地点になり、夜に使うと朝を迎えます。死亡しても持ちものを保持して再出発できます。

野草から種を集め、耕した土に植えると黄金麦を育てられます。苗はゲーム内90秒で収穫でき、若いうちは種だけが戻ります。森の葉や花から食材を探し、生き物から肉・革・羽を入手できます。地図で探索済みの地形を見渡し、クリックして次の目的地を記せます。

石、銅、鉄、星鋼へと装備を強化し、深い洞窟の星晶と、古代遺跡の紋章を集めましょう。旅の手帳に8章の目標があり、最後は「星の標」の制作につながります。クリエイティブでは88種類すべてのアイテムを創造のパレットから選べます。

## 実装内容

- 複数のノイズ場を組み合わせた草原、森、琥珀の森、砂丘、雪山、海岸、洞窟、鉱脈、樹木、遺跡。
- 16×16×96 のチャンク、最大2つの Worker による生成・メッシュ化、不可視面除去、Greedy Meshing、頂点の共有、隣接チャンクの判定、部分更新、遠方解放。
- 独自の16pxテクスチャアトラス、頂点AO、洞窟の陰影、光る素材、動く水面、昼夜の空と星、影、雲、雨。低品質設定では専用の軽量シェーダーを使います。
- 37ブロック、88アイテム、67レシピ、5段階の道具、耐久値、防具、翼衣、作業設備、栽培、箱の保管。
- 衝突、段差移動、しゃがみ、泳ぎ、落下・溺水・窒息・空腹ダメージ、回復、死亡と復帰。
- 6種の生物、地形・遮蔽を考慮した行動、攻撃の予備動作、被弾表示、アイテム落下と回収。
- Web Audio の環境音・旋律・操作音、インスタンス化したパーティクル。
- IndexedDB を使う複数ワールド保存、30秒ごとの自動保存、手動保存、JSON の書き出し・復元、設定保存。

セーブには地形変更、位置・状態、持ちものと装備、時間、生物・落下アイテム、箱、作物、進行、探索地図を含みます。保存はブラウザとアクセス先の組み合わせごとです。ブラウザのデータ消去に備え、タイトル画面のワールドカードからバックアップを書き出してください。

## 構成

`worldgen.js` はDOMに依存しない地形生成・メッシュ処理、`world.js` はチャンクの管理、`player.js` は物理と照準、`entities.js` は生物・戦闘・落下アイテム、`data.js` はデータ、`inventory.js` は持ちものとクラフト、`save.js` は永続化、`map.js` は探索地図、`scene.js` は空、`beacons.js` は星の標の演出、`performance.js` は実測に応じた解像度の調整、`audio.js` は音、`ui.js` は画面、`game.js` はゲーム全体の進行を担当します。

シングルプレイ用です。マルチプレイや他ゲームとのセーブ互換性はありません。高度な流体伝播や回路は実装していません。描画性能はGPUと描画距離に依存します。設定の品質・距離・自動調整を変更できます。クラウドではソフトウェア描画で検証しており、実GPUでのフレームレートや数時間以上の連続プレイ品質は未検証です。
